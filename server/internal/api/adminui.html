Konsol Admin

HP hilang? Ketik salah satu kode pemulihan.

Akun admin dibuat oleh super admin (menu “Admin” setelah masuk sebagai super admin). Kredensial super admin pertama dicetak di log server saat pertama kali dijalankan.

Aktifkan verifikasi 2 langkah

Wajib untuk akun admin . Cukup sekali — setelah ini setiap masuk meminta kode 6 digit dari HP.

  1. Pasang Google Authenticator di HP (Play Store / App Store).
  2. Di aplikasi, ketuk + → Pindai kode QR, arahkan ke QR ini.
  3. Ketik kode 6 digit yang muncul, lalu tekan Aktifkan.
Buka di Authenticator (bila halaman ini dibuka di HP)

Tidak bisa memindai? Pilih Masukkan kunci penyiapan di aplikasi dan ketik:
QR berganti bila halaman dimuat ulang — hapus entri lama di aplikasi bila sempat terpindai.

Simpan kode pemulihan

Dipakai bila HP hilang atau aplikasi terhapus: ketik salah satunya di kolom kode saat masuk. Setiap kode hanya sekali pakai dan tidak akan ditampilkan lagi. Cetak atau simpan di tempat aman, terpisah dari HP.
